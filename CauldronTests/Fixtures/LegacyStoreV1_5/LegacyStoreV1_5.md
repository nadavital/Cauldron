# Cauldron 1.5 SwiftData fixture

`default.store` is an empty, sanitized SwiftData database generated by launching
commit `521f071` (`Cauldron` 1.5, build `2026051801`) on an iPhone 17 simulator,
then terminating the app before copying the closed SQLite store.

The fixture contains schema metadata only—no user, recipe, CloudKit, or account
data. `CollectionRepositoryTests.testLegacyStoreFixtureOpensWithCurrentLocalSchema`
copies it to a temporary directory and requires the current schema to open it.

When a future release changes the persistent schema, retain this fixture and add
another fixture generated from the newest public release rather than replacing
the historical coverage.
